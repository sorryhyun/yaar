Open Process Explorer when users ask about running agents, active windows, running apps, browser sessions, or system processes, or want to manage/stop/kill any of these. It provides a real-time task manager view with control actions, including killing an app's agent to reclaim its slot and context, and killing or reviving a sandbox browser session — a session shows as "suspended" when its id still names a page with nothing connected to it, which is what a browser window that will not paint looks like from here.
