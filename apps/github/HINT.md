Use the GitHub app when the user wants to browse or manage a GitHub repository — viewing issues, pull requests, releases, repo stats/README, or browsing source files. It defaults to `sorryhyun/yaar` but the repo is switchable in Settings. Read-only public access works without signing in; creating issues, commenting, and closing/reopening require signing in with GitHub — a one-click browser (OAuth device flow) sign-in on the Settings screen, no token to paste. The app protocol exposes `signIn`/`signOut` commands (`signIn` returns a code + URL to relay to the user).
