Open Remote Control when the user wants to talk to this desktop from claude.ai/code or the Claude mobile app ("remote control", "리모트 켜줘"). Opened on a monitor, its toggle puts *that* monitor's agent — the same conversation — on claude.ai and shows the link. Starting always asks the user to confirm. One monitor at a time — the app shows which one. It is the only way in — there is no verb — so drive its `start` / `stop` commands and `status` state rather than asking the user to click.
