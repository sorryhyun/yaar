Route marketplace browsing, bulk updates and publishing here ("find an app for X", "update everything", "publish my app"); installing or uninstalling one known app id is the `marketplace` skill instead. Publishing needs the user to sign in and accept the Publisher Terms in this window themselves; ask them, never accept for them. A single `publish` routinely takes over 30s, so call it with timeoutMs ≥ 120000; for several apps use `publishAll` then block on `waitPublish`, never a batch of `publish` calls.
